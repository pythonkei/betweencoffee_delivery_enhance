## 核心訂單流程分析

### 訂單狀態流程圖
```
顧客下單 → 創建 OrderModel (status='pending', payment_status='pending')
    ↓
支付處理 (Alipay/PayPal/FPS/Cash)
    ↓
支付成功 → OrderStatusManager.process_payment_success()
    ↓
├─ 純咖啡豆訂單 → status='ready' (直接可取)
│
└─ 含咖啡訂單 → status='waiting' → 加入 CoffeeQueue
        ↓
    員工開始製作 → status='preparing' (倒計時開始)
        ↓
    製作完成 → status='ready' (待取)
        ↓
    顧客取餐 → status='completed'
```

### 核心文件職責表
| 文件 | 職責 | 狀態 |
|------|------|------|
| `eshop/models.py` | 訂單模型、商品模型、隊列模型 | ✅ 正常 |
| `eshop/order_status_manager.py` | 統一訂單狀態管理、支付成功處理 | ✅ 正常 |
| `eshop/queue_manager_refactored.py` | 咖啡製作隊列管理、智能分配 | ✅ 正常 |
| `eshop/views/payment_views.py` | 支付回調處理（Alipay/PayPal等） | ✅ 正常 |
| `static/js/staff-order-management/*.js` | 員工端訂單管理前端 | ✅ 正常 |

## 系統架構概覽

### 後端架構
- **框架**: Django + Django Channels (WebSocket)
- **數據庫**: PostgreSQL
- **部署平台**: Railway
- **即時通訊**: Redis + Channels (生產) / InMemoryChannelLayer (開發)

### 核心業務模塊
1. **商品管理**: CoffeeItem, BeanItem
2. **訂單系統**: 快速訂單、普通購物車訂單、智能分配系統
3. **支付系統**: PayPal、Alipay、FPS、現金支付
4. **員工管理**: 咖啡師工作負載顯示、訂單隊列管理
5. **WebSocket**: 訂單狀態推送、隊列位置更新
