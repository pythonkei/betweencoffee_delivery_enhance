# 優惠券系統使用指南

## 概述

Between Coffee 優惠券系統是一個完整的會員獎勵系統，包含優惠券管理、積分累積、會員編號分配等功能。本指南詳細介紹系統的設計、使用方法和技術實現。

## 系統架構

### 核心模型

#### 1. CustomerLoyalty (客戶忠誠度)
- **功能**: 管理用戶積分、消費記錄、會員編號
- **主要字段**:
  - `user`: 關聯用戶
  - `points`: 當前積分
  - `total_spent`: 累計消費金額
  - `total_orders`: 累計訂單數
  - `membership_number`: 會員編號
  - `join_date`: 加入日期

#### 2. CustomerCoupon (客戶優惠券)
- **功能**: 管理用戶優惠券
- **主要字段**:
  - `user`: 關聯用戶
  - `code`: 優惠碼 (唯一)
  - `coupon_type`: 優惠類型 (percentage/fixed/free_item)
  - `value`: 優惠值
  - `min_order_amount`: 最低消費金額
  - `valid_from/to`: 有效期
  - `is_used`: 是否已使用
  - `used_at`: 使用時間

#### 3. CustomerActivity (客戶活動)
- **功能**: 記錄用戶活動歷史
- **主要字段**:
  - `user`: 關聯用戶
  - `activity_type`: 活動類型
  - `description`: 活動描述
  - `metadata`: 額外數據 (JSON)

## 功能詳解

### 1. 優惠券創建

#### 自動創建
- **新用戶歡迎優惠券**: 用戶註冊時自動創建10%折扣優惠券
- **消費獎勵優惠券**: 達到特定消費金額時自動創建

#### 手動創建
```python
# 創建百分比折扣優惠券
coupon = CustomerCoupon.objects.create(
    user=user,
    code='WELCOME10',
    coupon_type='percentage',
    value=Decimal('10.00'),
    min_order_amount=Decimal('0.00'),
    valid_from=timezone.now(),
    valid_to=timezone.now() + timedelta(days=30),
    description='歡迎優惠券'
)

# 創建固定金額優惠券
coupon = CustomerCoupon.objects.create(
    user=user,
    code='FIXED20',
    coupon_type='fixed',
    value=Decimal('20.00'),
    min_order_amount=Decimal('100.00'),
    valid_from=timezone.now(),
    valid_to=timezone.now() + timedelta(days=60),
    description='滿$100減$20'
)
```

### 2. 優惠券驗證

#### 有效性檢查
```python
# 檢查優惠券是否有效
is_valid = coupon.is_valid()
# 返回 True/False，檢查:
# 1. 是否已使用
# 2. 是否在有效期內
# 3. 是否屬於當前用戶
```

#### 折扣計算
```python
# 應用折扣
discount, message = coupon.apply_discount(order_amount)
# 返回:
# - discount: 折扣金額
# - message: 應用結果消息
```

### 3. 積分系統

#### 積分計算規則
- **消費積分**: 每消費$10獲得1積分
- **積分公式**: `points = int(total_spent / 10)`

#### 積分更新
```python
# 訂單支付後自動更新積分
@receiver(post_save, sender=OrderModel)
def update_loyalty_on_order_paid(sender, instance, created, **kwargs):
    if instance.payment_status == 'paid' and instance.user:
        loyalty = CustomerLoyalty.objects.get_or_create(user=instance.user)
        points_earned = loyalty.add_points_from_order(instance)
```

### 4. 會員編號系統

#### 分配條件
- **消費金額**: 累計消費 ≥ $150
- **訂單數量**: 累計訂單 ≥ 3筆
- **編號格式**: `BC-XXXXXX` (6位數字)

#### 自動分配
```python
# 檢查並分配會員編號
membership_number = loyalty.check_and_assign_membership_number()
if membership_number and membership_number != '未分配':
    # 分配成功
    logger.info(f"用戶 {user.username} 獲得會員編號: {membership_number}")
```

## 使用流程

### 1. 用戶註冊流程
```
1. 用戶註冊
2. 自動創建 CustomerLoyalty 記錄
3. 自動創建歡迎優惠券
4. 記錄註冊活動
```

### 2. 訂單支付流程
```
1. 用戶支付訂單
2. 信號觸發積分計算
3. 更新累計消費和訂單數
4. 檢查是否分配會員編號
5. 記錄獲得積分活動
```

### 3. 優惠券使用流程
```
1. 用戶在購物車輸入優惠碼
2. 前端調用 apply_coupon API
3. 後端驗證優惠券有效性
4. 計算折扣金額
5. 標記優惠券為已使用
6. 記錄使用活動
```

## API 接口

### 1. 應用優惠券
- **URL**: `/profile/loyalty/apply-coupon/`
- **方法**: POST
- **參數**:
  ```json
  {
    "coupon_code": "WELCOME10",
    "order_amount": "100.00"
  }
  ```
- **響應**:
  ```json
  {
    "success": true,
    "discount": "10.00",
    "message": "已應用 10.00% 折扣"
  }
  ```

### 2. 獲取優惠券列表
- **URL**: `/profile/loyalty/coupons/`
- **方法**: GET
- **響應**: 返回分類的優惠券列表
  - `active_coupons`: 可用優惠券
  - `expired_coupons`: 已過期優惠券
  - `used_coupons`: 已使用優惠券

### 3. 獲取忠誠度信息
- **URL**: `/profile/loyalty/dashboard/`
- **方法**: GET
- **響應**: 返回積分、會員編號、消費統計等信息

### 2. JavaScript 集成
```javascript
// 應用優惠券
function applyCoupon() {
    const couponCode = document.getElementById('coupon-code').value;
    const orderAmount = calculateOrderTotal();
    
    fetch('/profile/loyalty/apply-coupon/', {
        method: 'POST',
        body: JSON.stringify({
            coupon_code: couponCode,
            order_amount: orderAmount
        }),
        headers: {
            'Content-Type': 'application/json',
            'X-CSRFToken': getCSRFToken()
        }
    })
    .then(response => response.json())
    .then(data => {
        if (data.success) {
            updateOrderTotal(data.discount);
            showSuccessMessage(data.message);
        } else {
            showErrorMessage(data.message);
        }
    });
}
```

## 錯誤處理

### 1. 常見錯誤
- **優惠碼不存在**: `優惠碼不存在`
- **優惠券已使用**: `此優惠券已被使用`
- **優惠券已過期**: `此優惠券已過期`
- **未達到最低消費**: `訂單金額需滿 $X.XX`
- **優惠券不屬於用戶**: `此優惠券不屬於您`

### 2. 錯誤處理策略
```python
try:
    coupon = CustomerCoupon.objects.get(
        code=coupon_code,
        user=request.user
    )
    
    if coupon.is_used:
        return JsonResponse({
            'success': False,
            'message': '此優惠券已被使用'
        })
        
    if not coupon.is_valid():
        return JsonResponse({
            'success': False,
            'message': '此優惠券已過期'
        })
        
except CustomerCoupon.DoesNotExist:
    return JsonResponse({
        'success': False,
        'message': '優惠碼不存在'
    })
```
