## 項目背景

### 🔍 問題識別
根據綜合工作總結報告，系統中存在兩個不同的WebSocket實現：

1. **顧客端WebSocket管理器** (`static/js/customer/websocket-manager.js`)
   - 使用簡單的重連機制（固定延遲）
   - 缺少智能退避算法
   - 缺少連接質量監控
   - 缺少離線訊息佇列

2. **員工端WebSocket管理器** (`static/js/staff-order-management/websocket-manager.js`)
   - 使用增強版實現（智能重連、離線佇列、連接質量監控）
   - 功能更完整，但與顧客端不一致

### 🎯 統一必要性
- **一致性**: 確保系統使用統一的WebSocket實現
- **穩定性**: 將員工端的增強功能帶到顧客端
- **可維護性**: 減少代碼重複，統一維護
- **用戶體驗**: 為顧客提供更穩定的實時更新

```
顧客端增強WebSocket管理器 (CustomerEnhancedWebSocketManager)
    ├── 繼承員工端WebSocket管理器核心功能
    ├── 保持顧客端原有API接口
    ├── 添加顧客端專用功能
    │   ├── 訂單狀態更新處理
    │   ├── 支付狀態更新處理
    │   ├── 隊列位置更新處理
    │   └── 訂單就緒通知
    └── 兼容性層
        ├── 舊API映射
        ├── 錯誤處理轉換
        └── 事件系統適配
```

### 📁 文件結構

```
static/js/customer/
├── websocket-manager.js              # 原始文件（已備份）
├── websocket-manager-enhanced.js     # 新增強版本（主文件）
├── websocket-manager.js.backup       # 原始文件備份
└── (通過兼容性層自動使用增強版本)
```

### 🔧 兼容性層實現

```javascript
// 兼容性層：透明升級
window.CustomerWebSocketManager = function(orderId) {
    console.log('🔄 使用增強版顧客WebSocket管理器（兼容模式）');
    
    // 創建增強管理器實例
    const enhancedManager = new CustomerEnhancedWebSocketManager(orderId, {
        customer: {
            showNotifications: false, // 兼容模式下關閉通知
            playSounds: false
        }
    });
    
    // 返回兼容性包裝對象
    return {
        // 保持原有API
        onStatusUpdate: (callback) => enhancedManager.onStatusUpdate(callback),
        onQueueUpdate: (callback) => enhancedManager.onQueueUpdate(callback),
        onPaymentUpdate: (callback) => enhancedManager.onPaymentUpdate(callback),
        disconnect: () => enhancedManager.disconnect(),
        cleanup: () => enhancedManager.cleanup(),
        
        // 內部引用（用於調試）
        _enhancedManager: enhancedManager
    };
};
```

### ⚙️ 配置選項

```javascript
const options = {
    // 重連配置
    reconnect: {
        baseDelay: 1000,      // 基礎延遲1秒
        maxDelay: 30000,      // 最大延遲30秒
        maxRetries: 10,       // 最大重試10次
        jitterFactor: 0.2,    // 隨機抖動±20%
        enableJitter: true    // 啟用抖動
    },
    
    // 心跳配置
    heartbeat: {
        enabled: true,        // 啟用心跳
        interval: 25000,      // 25秒間隔
        timeout: 10000        // 10秒超時
    },
    
    // 監控配置
    monitoring: {
        enabled: true,        // 啟用監控
        showIndicator: true,  // 顯示狀態指示器
        logLevel: 'info'      // 日誌級別
    },
    
    // 顧客端專用配置
    customer: {
        autoConnect: true,    // 自動連接
        showNotifications: true, // 顯示通知
        playSounds: false,    // 播放提示音
        notificationDuration: 5000 // 通知顯示5秒
    }
};
```
