## 優化目標

### 🔧 原始問題
根據綜合工作總結報告，WebSocket連接存在以下穩定性問題：
1. **重連機制不夠智能**：固定延遲重連（3秒），沒有指數退避
2. **心跳監控不夠完善**：只有客戶端發送ping，服務端沒有主動檢測
3. **錯誤處理不夠細緻**：錯誤分類不夠詳細，缺乏恢復策略
4. **缺乏連接質量監控**：沒有監控連接延遲、丟包率等指標

### 🎯 優化目標
1. **實現指數退避重連機制**
2. **增強心跳檢測和超時處理**
3. **創建基本的連接監控**
4. **完善錯誤分類和恢復策略**
5. **建立連接健康度評估體系**

### 🔄 重連算法

```javascript
// 指數退避公式：delay = baseDelay * 2^retryCount
let delay = this.baseDelay * Math.pow(2, this.retryCount);

// 限制最大延遲
delay = Math.min(delay, this.maxDelay);

// 添加隨機抖動 (±20%)
const jitterRange = delay * this.jitterFactor;
delay += Math.random() * jitterRange * 2 - jitterRange;
```

### 📊 健康度評分算法

```javascript
// 成功率權重：40%
score *= successRate * 0.4;

// 重試率權重：30%（重試越少分數越高）
const retryScore = Math.max(0, 1 - Math.min(retryRate, 1));
score *= retryScore * 0.3;

// 連續失敗懲罰：30%
const failurePenalty = Math.max(0, 1 - (failureStreak / 5));
score *= failurePenalty * 0.3;
```

## 使用指南

### 🛠️ 配置選項

#### WebSocket重連管理器配置
```javascript
const reconnectManager = new WebSocketReconnectManager({
    baseDelay: 1000,      // 基礎延遲（毫秒）
    maxDelay: 30000,      // 最大延遲（毫秒）
    maxRetries: 10,       // 最大重試次數
    jitterFactor: 0.2,    // 抖動因子（0-1）
    enableJitter: true    // 是否啟用抖動
});
```

#### 增強WebSocket連接器配置
```javascript
const connector = new EnhancedWebSocketConnector(wsUrl, {
    reconnectOptions: {
        baseDelay: 1000,
        maxDelay: 30000,
        maxRetries: 10,
        jitterFactor: 0.2,
        enableJitter: true
    },
    heartbeatEnabled: true,
    heartbeatInterval: 30000,  // 心跳間隔（毫秒）
    heartbeatTimeout: 10000    // 心跳超時（毫秒）
});
```

### 📱 開發監控

在localhost開發環境中，系統會自動顯示WebSocket監控面板：
- **位置**: 頁面右下角
- **內容**: 連接狀態、健康度、消息統計等
- **更新頻率**: 每2秒更新一次

### 🔧 故障排除

#### 常見問題解決方案

1. **連接頻繁斷開**
   - 檢查網絡穩定性
   - 查看健康度評分和重連建議
   - 考慮調整基礎延遲參數

2. **心跳超時**
   - 檢查服務器WebSocket實現
   - 調整心跳間隔和超時時間
   - 查看網絡延遲情況

3. **健康度評分低**
   - 查看詳細的連接統計
   - 分析連續失敗原因
   - 考慮手動重新連接

#### 調試工具
```javascript
// 獲取連接狀態
const status = connector.getConnectionStatus();
console.log('連接狀態:', status);

// 獲取重連管理器狀態

// 獲取重連建議
```
